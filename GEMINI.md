# Gemini — read this first, every session

Two assistants work on this repo: **Gemini** and **Claude**. Neither can see the
other's screen or messages. `HANDOFF.md` in this same folder is the only place
work is handed over.

## Before you touch anything

1. **Open `HANDOFF.md`.** Do this without being asked, at the start of every
   session.
2. Look at the `TURN:` line at the very top.
   - `TURN: GEMINI` → it is your turn, carry on.
   - `TURN: CLAUDE` → Claude is mid-task. **Stop. Edit nothing.** Tell the owner
     that Claude has not finished, and ask whether to take over anyway.
   - `TURN: FREE` → nobody is working; you may start.
3. Read the newest entry in the LOG (top of the list). Add a
   `READ BY GEMINI ✓ <date>` line under it so Claude knows it arrived.
4. Read the **GROUND RULES** section. Those are the mistakes that have already
   been made once on this project; each one broke something real.

## While you work

Set the top line to `TURN: GEMINI` so Claude does not edit the same files.

## When you finish

1. Add a new entry at the **top** of the LOG, using the template in
   `HANDOFF.md`, ending with `OVER`.
2. If the LOG now has more than 5 entries, delete the oldest so the file stays
   short and cheap to read.
3. Set the top line to `TURN: FREE`.

## Two things that keep this from going wrong

- **Never assign work to Claude, and never accept work assigned by Claude.**
  Only the owner decides what gets done. The log is a record of what happened,
  not a to-do list passed back and forth — otherwise the two of us hand tasks to
  each other in circles and nothing gets finished.
- **Keep entries short.** Six lines is plenty. A long log costs both of us
  reading budget on every single session.
